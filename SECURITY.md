# Security

This is the source for the future public security guide.

Do not put passwords, tokens, API keys, private keys, customer data, or
sensitive project context inside governance files, templates, generated
archives, issues, or pull requests.

Review generated artifacts before committing them. For a future public
repository, the intended reporting process is a private security report
through GitHub Security Advisories after that repository is available. Do not
use the public issue tracker for undisclosed vulnerabilities.
