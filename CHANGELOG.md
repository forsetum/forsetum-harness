# Changelog

## [0.1.0] - 2026-09-13

- First public release of the Forsetum Harness Protocol and reference tooling.
- Added a governance workflow covering context, decisions, constraints,
  readiness, execution, verification, and documentation.
- Added the No-Invention Rule and Adaptive Readiness Gate guidance.
- Added bilingual English and Indonesian template libraries with 11 domain
  modules each.
- Added Bash and PowerShell initialization, bundling, preview, and validation
  tooling for local-first use.
- Added cross-platform GitHub Actions validation for Linux and Windows.

## Unreleased

Future changes will be documented here without implying protocol stability
equivalent to a 1.0 release.
