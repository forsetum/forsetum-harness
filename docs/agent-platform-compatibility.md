# Agent adapter compatibility

| Status | Meaning |
| --- | --- |
| `Candidate` | A reference adapter with deterministic contract coverage; interactive adoption remains to be demonstrated on each intended agent and OS. |

Codex and Claude Code are Candidates. The product suite checks their documented
state mappings and runs the package inspector and decision handoff against
isolated fixtures. Cancellation, deferral, preservation, exact preview binding,
and backup preflight are executable checks. These do not demonstrate an agent's
conversational approval UX, skill discovery by a particular client, or complete
manual adoption across supported shells.

See [testing compatibility](testing-compatibility.md) for the five CI shell
jobs and the limits of their evidence. Live installation from GitHub through
`npx skills add forsetum/forsetum-harness` remains unverified. No runtime support
or certification is inferred from installation or a documented adapter.
