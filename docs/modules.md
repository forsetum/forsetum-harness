# Modules

All 27 canonical modules are approved for public distribution in English and
Indonesian. The curated exporter includes all 27 modules in both exported manifests
and the bundled skill runtime. Public
classification does not mean a complete 27-module release has been published.

The manifest remains the source of truth for IDs and metadata. One adoption
skill selects modules available in its bundled manifest; separate runtime
skills per module are not required.
