# Quality Standards & Acceptance Criteria — {{PROJECT_NAME}}

> This document defines universal quality standards, review checklists, and acceptance criteria.

---

## 1. Universal Acceptance Standards

Every task deliverable in `{{PROJECT_NAME}}` must satisfy:

1. **Completeness:** All task requirements documented in the approved plan must be implemented.
2. **Verification Evidence:** The agent must run verification commands or provide explicit proof before marking a task complete.
3. **Link Integrity:** All internal markdown links must resolve without broken paths.
4. **Clean Git State:** Work must be organized in focused, logical commits without unintended temporary files.

---

## 2. Review Workflow

Before a task or milestone is merged:
1. **Spec Compliance Review:** Confirm deliverable matches task text exactly (no missing or out-of-scope items).
2. **Quality Review:** Confirm deliverable adheres to project coding or stylistic standards.
3. **Documentation Sync:** Update `backlog.md`, decision registers, and corresponding module guides.
