2. **Protokol Pengendalian Hama & Penyakit Terpadu (PHT):**

## 3. Sortir Mutu Grading & Logistik Pasca-Panen

- [ ] Kriteria grading fisik (Ukuran Grade A/B/C, tingkat kematangan warna, dan toleransi cacat fisik) disepakati bersama offtaker.
- [ ] Ruang pendingin pasca-panen (*pre-cooling room*) beroperasi stabil sebelum pengangkutan armada logistik.
- [ ] Perhitungan Biaya Pokok Produksi (BPP per kg / per ekor) mencakup komponen bibit, pakan/pupuk, upah tenaga kerja harian, dan listrik irigasi.
- [ ] Surat jalan hasil panen mencatat nomor batch panen untuk ketertelusuran produk (*traceability*).
